# AU05 桌面端功能与页面规格

[开发文档入口](AU05开发设计.md) · [工程接口](独立设备接入.md) · [对应验收](构建发布与验收.md)

用户在其他应用里工作时，AU05 桌面端驻留在托盘或菜单栏。打开窗口后，沿用已确认的 SayAll 导航顺序与状态栏。以下规格中的“保存”表示桌面宿主已经持久化成功。写入失败时保留编辑内容并允许重试。设备离线时仍可编辑配置；页面应分别显示本地已保存和硬件可用状态。

### F01　连接、设置向导与输入工具

连接页从上到下显示设备、麦克风、输入工具和验证结果。首次启动在此页引导用户完成四步，完成后回到按键映射。再次启动恢复上次设备与配置。

1. 插入 AU05 接收器、开机，在连接页启用设备直控。按 K2 进行绑定测试，测试期间宿主消费该事件，避免向前台发送回车。同型号接收器身份不明确时提示用户只保留待测试的一台。
2. 从系统输入列表选择 AU05。用户主动启动短时试听，播放后清除临时缓冲。再次确认输入工具实际选用的麦克风；宿主的端点选择只能确定诊断目标。已选端点消失时显示“重新选择麦克风”。
3. 选择微信、豆包、Vokie、Typeless 或自定义工具，配置按住或点按切换、左右修饰键及组合键。提示用户先在目标工具内配置相同键值。第一轮兼容测试见验收章；每个工具的准备步骤随平台变化。
4. 提供普通测试输入框，再引导用户在真实应用测试。界面分别显示“收到按键”“已发触发键”“已检测到本次文本”或“请确认是否出字”。无法取得结果回调时以用户明确确认记录测试结果。后台切换窗口不得抢走输入焦点。

### F02　语音键、确认键、取消键和旋钮

按键页保留已确认的左右卡片和设备热点。点选动作格进入编辑面板，支持选择预设动作、用键盘录入、清除该格及恢复该键默认值。保存后更新卡片与当前配置。未设置的双击和长按保留可编辑空格。K1 专用面板显示输入工具、触发模式和“测试”，普通映射开关只控制 K2、K3 与旋钮。状态栏给出最近一次动作或错误。

普通键按上游默认值判定双击（约 300 ms）和长按（约 550 ms）。仅绑定单击时，按下即响应，可重复的滚动或导航操作可按住重复；启动应用、组合和文本插入每次按压只执行一次。配置双击后推迟单击判定，长按成立即取消待发单击，复杂手势禁止重复。旋钮按住旋转会消费本次按压，释放时抑制按压动作。旋钮同时绑定按压和按住旋转时，延至释放再提交短按，避免旋转前已发出 Backspace。K1 始终直接处理按下、松开。[SayAll 手势行为](https://github.com/HD838A/remote-mic-app#自定义遥控器按键)

### F03　组合动作与应用聚焦

组合动作页左侧列出名称与绑定次数，右侧按执行顺序显示步骤。用户可新建、复制、重命名，增删或调整步骤顺序，并试运行。例如“打开笔记”先激活指定应用，等窗口就绪，再发送该应用的聚焦快捷键。步骤类型为快捷键、启动或激活应用、聚焦输入框、媒体或滚动、插入常用语、有上限的等待。普通按键的动作选择器可引用已保存的组合。

执行前固定配置版本，按顺序执行；激活应用以窗口就绪及目标身份作为完成条件。等待超时、目标应用缺失、聚焦失败时停在失败步骤，显示步骤编号和重试入口。动作运行中再次触发同一组合只提示“正在执行”；取消、掉线、切换到意外窗口时停止后续步骤并释放键。重试由用户从头发起，清楚提示已完成步骤可能再次执行。限制组合引用为单层，避免循环引用。删除被引用的组合时展示受影响的绑定并在同一次保存中清除引用。

### F04　配置切换、导入与导出

按键页配置选择器支持新建、复制、改名、设默认、关联应用、导入、导出、恢复默认。自动切换使用 Windows 应用身份或 macOS bundle ID；标题变化不影响匹配。每台设备有一个默认配置；同一应用绑定冲突时，显示旧配置并由用户确认替换。自动跟随开启时，手动选择立即生效，下次前台应用改变后重新匹配；关闭后保留手选结果。

桌面程序根据当前应用切换本地配置。设备通道断开时显示按键触发不可用。按住 K1 或正在执行组合时锁定启动时的配置，结束后再应用新配置。导入先预览支持的绑定、缺失的本机应用和无对应的旧遥控器按键，显式选择“另存”或“替换”。取消导入保留原配置。

### F05　统计

统计页选择日、周或全部，展示实体按压次数、语音使用时长和最长单次排行。一次有效按下计一次；重复上报、软件生成的快捷键和诊断模式的测试事件排除。旋转单列为旋钮步数，避免膨胀按键次数。时长取有效按下至松开的单调时钟差值。中断会话单列，无法确定终点的会话排除出排行。以用户本地时区展示日期，跨午夜的时长按区间切分，排行保留完整会话。无记录时展示零值；清空统计须确认，回眸历史独立保存。[上游统计页面](https://github.com/HD838A/remote-mic-app#使用统计)

### F06　回眸与常用语

回眸页默认显示“记录回眸”关闭。开启时告知记录范围；按日期和应用浏览、搜索、复制、删除单条或清空。关闭后停止新增，保留用户已有记录。只接收能同时验证会话、目标和最终提交文本的适配器事件。纯热键模式可能正常出字却没有可信回传，此时显示“此工具支持听写，暂不支持回眸”。切换到其他应用、取消、密码框、只有临时识别结果时均丢弃候选。禁止通过全局剪贴板历史或整窗读取推测内容。同一会话重复回调只入库一次。

常用语可手动创建，也可由用户把一条回眸保存为短语。编辑器含名称与正文，支持编辑、删除、绑定键位和在普通输入框试插入。仅向用户当前选定的可编辑目标插入一次。删除回眸不会连带删除已另存的常用语，删除常用语须清理引用它的绑定或组合步骤并提示。平台输入接口受限时显示“可复制”，由用户自行粘贴。

### F07　本地 Agent 只读访问

回眸内单独提供“本地 Agent 访问”。选择客户端、显示可读范围、生成独立授权并给出 stdio 配置，设置页支持检查连接、撤销单个客户端或全部撤销。检查连接只读服务状态和工具清单。提供按时间和应用分页列出摘要、按 ID 读取一条已保存记录的工具；每次读取重验授权及总开关。客户端无权模拟输入、执行组合或修改历史。界面明确说明授权的客户端可把读到的内容交给其模型。若用户启用自动配置，先备份现有配置，遇到同名条目或无法解析的文件改为提供手动片段。[上游 Agent 接入说明](https://github.com/HD838A/remote-mic-app/blob/main/AI_SETUP.md)

### F08　权限、诊断与故障恢复

权限页逐项显示当前系统、触发权限的进程、所需操作、如何重新测试。Windows 区分输入工具的麦克风访问、诊断用麦克风访问和向目标窗口发送按键的权限；高权限窗口无法接收时保留普通权限，提示换普通窗口复验。macOS 区分宿主的辅助功能、麦克风及输入监控权限。麦克风测试由打开音频端点的进程请求权限。权限拒绝时仅禁用依赖功能。

诊断摘要列出软件版本、连接代次、绑定数量、事件到达与失败阶段，可预览后复制。默认省略实际按键文本、录音、设备地址、窗口标题、个人路径及授权凭据。重新检测只刷新状态；测试按键、试听和清空数据都有独立入口。

### F09　关于、偏好设置和更新

关于页显示桌面端版本、接收器状态和 HID 通信状态，列出开源归属、项目链接和检查更新。偏好设置含跟随系统或手动深浅色、登录启动、检查更新和诊断入口。注册登录启动失败时开关还原并解释原因。下载失败保留当前版本；升级前检查配置版本和设备兼容性，录音或组合执行期间推迟重启。Windows 托盘和 Mac 菜单栏分别提供打开窗口及退出，退出前收尾活动会话。

### F10　分享

左下“分享”使用用户明确选择的内容生成本地分享预览。默认是派生项目说明和发布链接；尚无正式发布地址时隐藏复制链接操作。分享键位方案调用同一个配置导出流程，展示将包含的配置名、绑定及被引用的常用语正文，后者默认排除。提供保存文件或复制选定文本；操作成功仅表示本地导出。历史、统计、设备身份、个人路径和 Agent 凭据始终排除。此处为 AU05 版本的分享交互约定。

### F11　AU05 状态、灯效与脱机

设备卡分别显示连接、可用能力与电量。收到可靠数值才显示百分比；掉线时清除当前值或明确标记为上次读取。接收器返回可靠的机身在线状态或电量时更新显示，过期读数自动清除。灯效、硬件降噪、休眠及固件设置需分别确认可用协议和操作结果后开放。退出直控后释放订阅，掉线中止活动会话。AU05 普通版作为验证对象，联名款单独验证。
