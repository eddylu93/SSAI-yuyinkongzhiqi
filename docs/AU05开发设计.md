# AU05 独立桌面软件开发设计

用户在其他应用中按住 AU05 的语音键，说完松开，文字进入原输入框。确认键、取消键和旋钮可以映射到系统操作。桌面软件直接读取接收器和麦克风，在没有安装或运行 Ulanzi Studio 的机器上完成全部核心功能。Windows 是首个真机验证平台，macOS 单独构建与验收。

## 界面基准

以用户提供的 SayAll 截图 为布局基准，中央使用 [AU05 原图](界面素材/AU05.png)。窗口基准尺寸为 1020 × 772。左栏保留按键、组合动作、统计、回眸、连接、权限、关于与分享。旋钮的卡片位于设备左侧，语音、确认、取消位于右侧。点击热点高亮对应曲线。右上设备卡显示接收器、机身以及电量状态。点击设备卡可查看直控订阅、输入接口与实体键测试。[Windows 独立版实拍](界面素材/AU05独立版运行.jpg)

## 运行链路

1. 宿主用系统接口发现 AU05 接收器，在后台读取限定来源的输入。连接页可订阅接收器的按键直控事件；标准 HID 兼容方式支持按键及旋钮校准。两种方式均可在诊断模式下验证。
2. 设备输入转化为按下、松开、转动或按住转动。手势引擎根据当前配置分派动作。掉线时取消会话、释放模拟键并清除未决手势。
3. K1 独立控制语音触发。Windows 本地中文识别器直接使用已选麦克风，向有效的当前编辑控件提交文本。外部输入工具通过用户配置的快捷键触发。
4. 统计、应用配置、组合、常用语、授权与可选回眸保存在本机。分享文件排除设备识别模式、音频、历史及授权凭据。只读 MCP 通道与设备采集相互独立。

## 对齐范围

- 连接与按键。区分接收器、实时报告、校准、语音采集和最终出字。K2 默认 Enter，K3 默认 Esc，旋钮按下默认 Backspace，左右旋转默认滚动。单击、双击、长按及旋转需要逐项验证。
- 组合动作与逐应用配置。支持编辑、试运行、取消和本地导入导出；选择应用身份时采用平台标识。窗口切换、超时和断线中止后续步骤。
- 统计、常用语与回眸。诊断事件排除出统计；可信最终文本可在用户启用后保存并通过按客户端授权的本地 helper 读取。
- 发布与维护。Windows 安装包提供前端、宿主、本地识别和 HID 后端。macOS 的输入权限、架构构建、签名和真机结果单独记录。

完整的页面需求及实现状态分别见[功能与页面规格](功能与页面规格.md)、[独立设备接入](独立设备接入.md)和[构建发布与验收](构建发布与验收.md)。
