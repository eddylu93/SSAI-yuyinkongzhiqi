# AU05 Desk 界面规范

适用于 0.4.0 起的 Windows 桌面界面。组件样式和主题色以 [src/style.css](../src/style.css) 为准。

## 布局与导航

保留 SayAll 的左侧导航、右上设备入口、中央 AU05 实物图和底部状态栏。基准窗口为 1020 × 772，最小窗口为 830 × 620。侧栏常规宽 102px，紧凑宽 84px。只有内容区滚动；切换页面或分区后回到顶部。按键页左列放旋钮，右列放语音、确认和取消键。连线随布局变化重新计算。

| 入口 | 主要任务 |
| --- | --- |
| 按键 | 选择按键配置，查看动作，点动作格编辑。语音卡直接进入语音输入设置。 |
| 组合动作 | 创建组合，编辑执行顺序，试运行和停止。 |
| 统计 | 选择时段，查看实体按压次数、累计语音时长、最长单次和按键使用分布。 |
| 回眸 | 分开浏览听写记录、常用语和客户端授权。 |
| 连接 | 分为设备连接、语音输入、按键测试。直控开关位于设备连接页。 |
| 权限 | 查看系统设置、测试按键、预览和复制诊断摘要。 |
| 关于 | 应用设置管理外观及登录启动；按键配置管理配置名称与应用关联。 |
| 分享 | 先预览将导出的配置，导入另设入口。 |

## 视觉与交互

| 项目 | 统一规则 |
| --- | --- |
| 字体 | Windows 使用 Segoe UI 和 Microsoft YaHei UI。页标题 25px，卡片标题 16px，正文 14px，说明 12px。 |
| 间距 | 页面内边距 24px，窄窗 18px。按钮组间隔 8px，内容卡片间隔 14px。 |
| 容器 | 面板圆角 12px，表单控件 7px。深浅主题共用语义颜色变量。 |
| 操作 | 主要操作用蓝色实底，次要操作用中性底色。可选分区用蓝色下划线和文字标识，键盘焦点显示 2px 外框。 |
| 下拉选择 | 收起时用 7px 圆角和细箭头，展开菜单用 10px 圆角和面板底色。选中项显示主题强调色与勾选标记，键盘焦点独立描边。长选项可换行，长列表可滚动。 |
| 映射 | 已绑定手势显示动作名，空手势保留「未设置」与编辑入口。卡片与实体热点共同高亮。 |
| 状态 | 在线显示圆点和文字；电量有读数才显示百分比。接收器、机身及订阅状态各有单独字段。 |
| 反馈 | 成功反馈位于底栏。表单错误在操作所在页面或弹窗显示。删除统计、组合、短语和授权沿用各自的确认流程。 |
| 弹窗 | 标题写出正在编辑的控件和手势。底部按「取消」「保存动作」排列；保存失败保留编辑值。 |
| 空状态 | 使用实际原因和可执行的下一步。统计中没有记录的时段不绘制模拟使用量。 |

## 改动验收

新界面需核对深色、浅色、默认与最小窗口；操作应能通过 Tab 和键盘激活。分区切换本身不得改变硬件订阅或退出测试模式。听写及硬件功能按[真机验收记录](构建发布与验收.md)单独验证。
